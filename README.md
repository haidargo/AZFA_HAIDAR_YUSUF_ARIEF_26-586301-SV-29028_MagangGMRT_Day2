## 4. Cara Instalasi & Menjalankan Program

### A. Persyaratan
- Python 3.x
- Library yang tercantum dalam requirements.txt

### B. Instalasi Library

Jalankan perintah berikut pada terminal:

pip install -r requirements.txt


### C. Menjalankan Program

1. Clone atau download repository GitHub.
2. Buka folder proyek melalui terminal.
3. Jalankan perintah:

python main.py

4. Amati hasil program dan visualisasi yang dihasilkan.
